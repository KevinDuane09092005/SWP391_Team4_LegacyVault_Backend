# SWP391_Team4_LegacyVault_Backend

Backend API for the LegacyVault Digital Asset Handover System.

Flow 5 Legal Verification is documented in [`docs/flow5-legal-verification/README.md`](docs/flow5-legal-verification/README.md). It is implemented against the existing DMS handover, asset assignment, beneficiary contact, and JWT authentication models.

Run the backend tests with `./mvnw test` (Windows: `mvnw.cmd test`).
